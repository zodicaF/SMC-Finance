# Transfer Tracker

Bank transfer request tracker. Plain JavaScript, no framework, no build step.
Start with `CLAUDE.md` and `docs/BUILD_PLAN.md`.

```
npm install
npm run fonts     # only if public/fonts is empty
npm run dev       # http://localhost:3000
npm run test
npm run lint
npm run check
```

`public/` is the whole website: what is in that folder is what gets deployed.
